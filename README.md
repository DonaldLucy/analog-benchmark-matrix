# Analog Benchmark Matrix

A side-by-side comparison of 38 published benchmarks and datasets for analog circuit design automation (2023 to October 2026), covering DAC, ICCAD, DATE, ASP-DAC, NeurIPS, ICML, ICLR and other venues, with the gLayout textbook-sharing benchmark ([ReaLLMASIC/gLayout#127](https://github.com/ReaLLMASIC/gLayout/pull/127)) as the last row.

View the page: https://donaldlucy.github.io/analog-benchmark-matrix/
